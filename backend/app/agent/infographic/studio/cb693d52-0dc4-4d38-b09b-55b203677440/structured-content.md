## Design Instructions

### Color Theme
- 主色调：红色（用户指定）
- 背景：暖复古米色/米白色 (#F5F0E6)
- 强调色：鲑鱼粉、天蓝、芥末黄、薄荷绿（复古色调）
- 对比色：纯黑 (#000000) 和纯白 (#FFFFFF)

### Special Element
- 在图的右上角绘制一个蓝精灵玩偶（蓝色小精灵形象，卡通风格）

### Layout
- bento-grid 布局：模块化网格，不同大小的单元格组合
- 英雄单元格用于主标题
- 各内容模块分布在不同大小的单元格中

### Style
- retro-pop-grid: 1970 年代复古波普艺术风格
- 瑞士国际主义网格系统
- 粗黑轮廓线
- 扁平色块
- 无渐变、无阴影、无 3D 效果

### Aspect Ratio
- 横向 16:9

### Language
- 简体中文
