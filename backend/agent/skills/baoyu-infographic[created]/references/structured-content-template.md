# Structured Content Template

Use this template to create the stage-two infographic brief.

## Output Requirements

- Write markdown only.
- Keep the brief optimized for a single infographic image.
- Preserve source facts, but compress wording aggressively.
- Prefer 3 to 6 major sections.
- Each section should have a clear headline and short supporting bullets.

## Additional Guidance

- If the source is large, merge overlapping points before writing sections.
- If the source is narrative, convert it into categories or phases.
- If the source is data-heavy, surface only the numbers that change the story.
- If user instructions exist, include them in `## Prompt Notes`.
