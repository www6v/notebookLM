# Layout Reference: Hierarchical Layers

Use a hierarchical-layers layout when the content has clear levels, tiers, or nested importance.

## Structure

- One title block introducing the hierarchy.
- Three to six layers arranged vertically or concentrically.
- Each layer represents a level of importance, dependency, or abstraction.
- Supporting callouts can sit beside the main layered structure.

## Best Use Cases

- Concept hierarchies
- Capability stacks
- Priority models
- Foundation-to-outcome explanations

## Composition Guidance

- Make the layered structure visually obvious at a glance.
- Give each layer a distinct color or visual treatment.
- Use arrows, spacing, or nesting cues to show progression.
- Keep labels inside layers short and readable.

## Text Guidance

- Each layer should communicate one clear idea.
- Supporting notes should stay outside the core hierarchy when possible.
- Preserve only the labels and facts needed to understand the stack.

## Failure Modes To Avoid

- Too many layers
- Ambiguous ordering
- Equal emphasis on every tier
- Long paragraph text inside the layered blocks
