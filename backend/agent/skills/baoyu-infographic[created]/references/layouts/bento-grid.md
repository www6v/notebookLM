# Layout Reference: Bento Grid

Use a modular bento-grid layout for information that benefits from grouped cards.

## Structure

- One strong title area at the top.
- A medium-sized hero summary block near the top third.
- Three to six supporting cards arranged in an asymmetric but balanced grid.
- One footer strip or side rail for supporting facts if needed.

## Best Use Cases

- Topic overviews
- Multi-point summaries
- Grouped comparisons
- Educational explainers

## Composition Guidance

- Vary card size to show hierarchy.
- Keep the eye moving left-to-right and top-to-bottom.
- Reserve the largest card for the main thesis, framework, or conclusion.
- Use icons, mini diagrams, and short labels instead of dense paragraphs.

## Text Guidance

- Keep headlines short.
- Use compact bullets or two-line blurbs.
- Avoid placing long sentences in small cards.

## Failure Modes To Avoid

- Too many equally sized cards
- Tiny text crammed into corners
- Weak visual hierarchy
- Decorative clutter that competes with content
